# analise-cancelamento-cartao
 Análise de Cancelamento de Cartões

Projeto desenvolvido no Google Colab com Python, focado na análise dos fatores que levam os clientes a cancelar o cartão.

# Tecnologias
- Python
- Pandas
- Matplotlib
- Seaborn

# Objetivo
Identificar padrões e insights que apoiem a tomada de decisão.
